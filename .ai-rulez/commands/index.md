# Concepts

- [Build](build.md) - Build voom and report warnings — debug by default, release with --release
- [Poly Check](poly-check.md) - Lint and check formatting with poly — apply no fixes; summarize findings and drift
- [Poly Fix](poly-fix.md) - Apply poly lint --fix and fmt --fix, then re-check and report what changed and what remains
- [Test](test.md) - Run the test suite and report failures, with attention to the safety fixtures
